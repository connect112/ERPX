# Certificate fonts

Script fonts used for the student's name (and optionally the certificate ID) on certificates.
All are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files here); they may be bundled and used freely.

| Layout key      | Font           | Source |
|-----------------|----------------|--------|
| `great_vibes`   | Great Vibes    | https://fonts.google.com/specimen/Great+Vibes |
| `allura`        | Allura         | https://fonts.google.com/specimen/Allura |
| `alex_brush`    | Alex Brush     | https://fonts.google.com/specimen/Alex+Brush |
| `pinyon_script` | Pinyon Script  | https://fonts.google.com/specimen/Pinyon+Script |
| `parisienne`    | Parisienne     | https://fonts.google.com/specimen/Parisienne |

The admin web app serves the same files from `apps/web/public/fonts/` for the live preview in the designer.
